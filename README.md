# 页间 · PageNest

一个本地优先的阅读工作台：把 **TXT / Markdown / PDF / Word / HTML / EPUB / 微信公众号文章** 放到同一个书架里阅读，并提供 **右键快捷搜索、联网问答、读书笔记、跨书概念树、可以手动编辑和自动生成的思维导图**。

所有书籍、笔记、问答与导图都保存在本机 `data/` 目录，不需要注册账号。当前数据已初始化，只保留书架上的三本书。

## 第一次使用（无需安装 Node）

1. 双击项目根目录的 **`初始化.cmd`**。
2. 等待 1–3 分钟：程序会自动检测系统架构，从内置离线包安装 Node 到 `runtime\` 子目录。
3. 安装完成后浏览器自动打开 **http://127.0.0.1:4173**。
4. 桌面会自动生成 **「页间 PageNest」** 快捷方式，以后双击它即可。

初始化器特点：

- 不需要管理员权限，不修改系统 PATH，不写注册表
- 支持 Windows x64 / ARM64
- 内置 Node v24.22.2 离线包，无网络也能安装
- 自动校验 SHA256，失败会回滚并提示
- 不删除书籍或笔记；只清空 `data/settings.json` 中的 `ai.apiKey`
- **每次初始化都会清空 `data/settings.json` 中的 `ai.apiKey`**，需要重新填写 API Key；模型地址、模型名和界面设置保留
- 如果 `.cmd` 被系统策略拦截，可在项目目录运行：
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File bootstrap\bootstrap.ps1
  ```
- 如果移动了整个文件夹，重新运行一次 `初始化.cmd` 刷新快捷方式路径即可；书籍数据不会受影响。

## 开发/手动启动

已经初始化过 Node 时：

```powershell
runtime\node-v24.22.2-win-x64\node.exe launcher.js
```

或者使用系统 Node：

```powershell
npm install --ignore-scripts
npm start
```

浏览器打开 **http://127.0.0.1:4173**。

> 前端已构建在 `dist/`。修改 `src/` 后运行 `npm run build` 再刷新页面。
> Windows 下若 PowerShell 禁止运行 npm 脚本，请使用 `npm.cmd`。

## 功能

### 书架与导入

- 拖放或选择 TXT、Markdown、PDF、DOCX、DOC、HTML、EPUB 文件，单个文件最大 60MB。
- 粘贴微信公众号文章链接或普通网页链接，自动提取标题、作者与正文，图片下载到本地。
- 微信拦截自动访问时，可以复制文章正文，用「粘贴正文」导入。
- 自动识别 UTF-8 / UTF-16 / GB18030 编码；文本按章节标题自动切章。
- 书籍进度、最近阅读、格式筛选与全书内容搜索。

### 阅读器

- HTML 文本阅读：四种纸张主题、字号、行距、版心宽度可调。
- **滚动 / 翻页两种模式**：翻页模式使用 CSS 多栏分页，字号、行距、版心变化会自动重新分页，左右方向键翻页。
- PDF 阅读：连续滚动、文字层可选中、页码跳转、缩放、适合宽度、PDF 大纲。
- 阅读进度自动保存；支持从搜索结果直接跳到章节或 PDF 页码。
- 选中文字右键：在本书搜索、在书库搜索、必应/百度/Google 网页搜索、就这段内容提问、保存为笔记、复制。
- 书内搜索支持关键词高亮与结果跳转。

### 阅读器侧边模块

- 阅读时点击顶栏的问答 / 导图 / 笔记按钮，右侧会挂出对应模块，不需要离开正文。
- 三个模块可以在同一侧栏切换；手机端自动变为全屏抽屉。
- 问答默认保持原来的「打开 / 收起」模式；侧栏顶部的「常驻」可以把问答固定在右边，刷新后自动打开。
- 侧栏与正文之间有一条可拖动的分隔条，左右拖动可自由调整问答宽度；双击恢复默认宽度，宽度会记住。
- 问答面板整体字号已放大，正文回答、模式说明、来源卡片与输入框都更易读。
- 右键选中文字选择「就这段内容提问」或「保存为笔记」，会自动打开对应侧栏并带入选中内容。

### 快捷问答

- **严格素材模式**：只使用当前章节或当前书籍的原文，禁止调用模型自身知识；原文不足时明确说明。适合解读原文、文本问答、做题。
- **自由拓展模式**：素材作为参考，允许调用模型自身知识，外部信息标注“补充背景”。适合延伸讨论、人物时代、概念解释与背景查询。
- **联网补充开关**：开启后先做本书 RAG 检索，再联网搜索；书本素材永远排在搜索结果前面。搜索查询会结合原文优化，5 分钟缓存，最多 4 条结果，自动去重、过滤广告与低质短视频来源、截断摘要。追问会沿用上一轮主题；纯“详细一点”等泛化查询没有主题时会跳过搜索。实际检索词会显示在来源上方。回答中书本内容标【原文】，网络内容标【网络来源】并附 URL；无搜索结果时自动移除联网区块。
- 可以选择「本节 / 本页 / 全书」范围；严格模式在未配置 AI 时自动退回本地检索。
- 对话记录保存在本地，可随时回看或删除。

### 读书笔记

- 每本书独立保存笔记，选中文字右键即可摘录，也可以手动写评论。
- 笔记支持分类、编辑、删除；AI 可以按主题分类、生成标题与摘要，并给出整理概览。
- 每本书的笔记可导出为独立的 Word 文档（`.docx`），按分类分页排版，保留原书引文与出处；每次新增、编辑、AI 整理后会自动同步 `data/notes-word/` 下的该书的 Word 快照。

### 概念树

- 主页面新增「概念树」板块，也可以从侧边栏进入。
- 选择多本书和一个主题，从不同书中检索原书片段，生成为一棵跨书概念树。
- 每个概念节点包含：概念名、定义、与父概念的关系、原书引文（书名 / 章节 / 页码）。
- AI 负责梳理概念之间的前提、从属与回应关系；生成后可以手动增删节点、改写定义与关系。
- 概念树独立于单本书笔记，适合学术研究式整理。

### 思维导图

- 同一本书可以保存多张导图，按「当前章节」「整本书」「一个概念」分别组织。
- 阅读器侧栏直接查看本书全部导图，切换预览，或新建。
- 从书自动生成：本地结构提取（离线可用）或 AI 深度提炼（需要配置 AI）。
- **AI 指令改图**：在侧栏输入「精简为 3 个主分支」「补充本节例子」等指令，AI 会在现有导图基础上继续修改。
- 手动编辑：双击节点改字、Tab 加子节点、Enter 加同级、Delete 删除、上移/下移、备注。
- 平移、滚轮缩放、适应画布、撤销/重做、自动保存。
- 四种主题，导出 PNG、SVG、Markdown 大纲、JSON 数据。

### 界面与显示

- 默认深色学术极简主题：近黑中性底色、细边框、低饱和暖金/冷青强调色，阅读正文保留衬线排版。
- 右侧新增独立显示栏：顶部是常驻「护眼」开关，一键切换暖色低刺激配色；下方是「Aa」显示控制，不覆盖正文，面板向左展开。
- 「Aa」显示控制面板提供 **全局字号 90% / 100% / 110% / 120%**，界面与阅读正文一起缩放，刷新后保持。
- 阅读器目录可以一键隐藏/展开，状态会记住；手机上仍以抽屉方式打开。

### AI 配置

进入「设置 → AI 服务」，支持任何 OpenAI 兼容的 Chat Completions 接口：

- DeepSeek（推荐）：`https://api.deepseek.com`，模型 `deepseek-chat`
- OpenAI：`https://api.openai.com/v1`，模型 `gpt-4o-mini`
- 自定义：填写 API 地址与模型名

API Key 只保存在本机 `data/settings.json`，不会显示在页面上。也可以使用环境变量 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY`。

## 数据与备份

```
data/
├── library.json       # 书架元数据与进度
├── books/             # 每本书的正文、章节与文本
├── files/             # 原始 PDF / Word / EPUB 等文件
├── assets/            # 网页导入时缓存到本地的图片
├── maps.json          # 思维导图
├── notes.json         # 每本书的笔记与 AI 分类结果
├── notes-word/        # 每本书单独的读书笔记 Word 文档
├── concepts.json      # 跨书概念树
├── threads.json       # 问答记录
└── settings.json      # AI 设置
```

复制整个 `data/` 文件夹即可备份或迁移书架。删除书籍时会同时删除原始文件与正文；关联导图会保留，只解除书籍链接。笔记与 Word 导出按书生成，每本书各自独立。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl / ⌘ + K` | 聚焦全局搜索 |
| `Ctrl / ⌘ + F` | 在书中搜索 |
| `选中文字后右键` | 快捷搜索 / 提问 / 保存笔记 / 复制 |
| `← / →` | 阅读时切换章节；翻页模式翻页 |
| `Tab` | 导图中添加子节点 |
| `Enter` | 导图中添加同级节点 |
| `F2` | 导图中编辑节点文字 |
| `Ctrl / ⌘ + Z` | 撤销导图修改 |

## 已知边界

- 扫描版 PDF 没有文字层，只能阅读页面图像，无法选中文字或做文本检索；导入后会在阅读器和问答侧栏提示，需先用 OCR 加文字层再重新导入，或用「粘贴正文」导入 OCR 结果。
- 旧版 `.doc` 仅提取纯文本，复杂排版会丢失。
- EPUB 以正文与内嵌图片为主，不保留原书 CSS 排版。
- 微信文章的自动抓取受微信风控影响，失败时请使用「粘贴正文」。
- 联网搜索依赖公开搜索结果页，可能受网络、地区或反爬策略影响；无有效结果时会自动退回仅使用本书素材。
- AI 问答、AI 导图、AI 笔记整理与 AI 概念树需要自备兼容接口的 API Key；不配置时不影响阅读、搜索和本地导图。
